# 🖥️ CPU Process Schedule Visualizer
An application built with **Python & Tkinter** that simulates 4 types of CPU process scheduling algorithms, visualizing them with **Gantt Chart** and the **Scheduling table**

## 🚀 Scheduling Algorithms Supported
- First Come First Serve (FCFS)
- Shortest Remaining Time First (SRTF)
- Round Robin (RR)
- Non-preemptive Priority Scheduling

## ✨ Features
- Input- Select required Algorithms, Add or Remove required number of process
- Option to set arrival time for all process to 0 based on user requirement
- Gantt Chart and Scheduling Table Visualization

## 🛠️ How to run
- Make sure to install python3
- Run command **python3 gantt.py"
